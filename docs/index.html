🏛️ API da Câmara dos Deputados

API pública e gratuita com dados de deputados, proposições, votações e despesas. Endpoints utilizados: /deputados, /proposicoes, /votacoes, /partidos. A API retorna dados paginados — o extrator percorre todas as páginas automaticamente.

🐍 Extração com Python

Script src/extractor.py realiza chamadas HTTP com a biblioteca requests, trata paginação automática via loop while, implementa retry com backoff exponencial (2s, 4s, 8s) e salva os JSONs brutos em data/raw/ com timestamp — garantindo rastreabilidade de cada extração.

🐼 Transformação com Pandas

Script src/transformer.py carrega os JSONs, normaliza campos aninhados com pd.json_normalize(), valida campos obrigatórios, remove duplicatas, converte tipos e renomeia colunas para snake_case. Zero registros inválidos encontrados nos dados da Câmara.

🐘 PostgreSQL no Supabase

Banco de dados PostgreSQL 17 hospedado no Supabase. Modelo com 2 tabelas dimensão (deputados, partidos) e 2 tabelas fato (proposicoes, votacoes). Total de 16.552 registros carregados. Script src/loader.py usa SQLAlchemy com inserção em lote de 500 registros.

🤖 Camada de IA

Script src/ai_layer.py usa o modelo text-embedding-3-small da OpenAI para gerar embeddings das ementas e classificar por tema via similaridade de cosseno. O modelo gpt-4o-mini gera resumos executivos em 2 linhas para cada proposição. Custo médio: $0,0003 por 20 proposições.

⚡ Automação com n8n

Workflow Bússola Pública — Alerta Semanal publicado no n8n cloud. Executa toda segunda-feira às 6h: consulta SQL no Supabase buscando as 5 proposições mais relevantes com tema e resumo IA, formata em HTML e envia por email via Gmail automaticamente.
